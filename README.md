# stop-watch
클로드 코드로 만든 스톱워치

한강 야경과 낮 풍경을 배경으로 한 웹 스톱워치입니다. 유람선과 요트가 강 위를 지나가고, 하늘에서는 불꽃놀이가 터집니다.

## 기능
- **시작 / 정지 / 초기화** 버튼 (정지 후 다시 시작하면 이어서 측정)
- 1/100초까지 표시하는 숫자 시계와 아날로그 다이얼
- 단축키: `Space` 시작/정지, `R` 초기화
- 기기 설정에 따라 라이트(낮) / 다크(밤) 테마 자동 전환
- 모션 줄이기 설정을 켜면 배경 애니메이션이 멈춥니다

## 실행 방법
설치나 빌드 없이 `index.html`을 브라우저로 열면 됩니다.

## 파일 구성
| 파일 | 내용 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 디자인과 테마 색상 |
| `stopwatch.js` | 스톱워치 동작 |
| `scene.js` | 한강 배경 애니메이션 (스카이라인, 유람선, 요트, 불꽃놀이) |
